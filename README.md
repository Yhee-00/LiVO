# Livo
온라인 강의 예약 플랫폼

## Tech Stack
- Backend: Spring Boot, JSP JPA 
- Frontend: HTML, CSS, JavaScript
- DB & Infra: MariaDB, AWS EC2, RDS, Nginx
- External API: Open AI, TossPayments

## My Role
- 강의 예약 서비스의 핵심 비즈니스 로직 설계 및 구현
- Toss Payments 결제 · 환불 로직 연동
- Spring Scheduler 기반 강의 상태 자동 갱신
- AWS 기반 서비스 배포 및 인프라 구성
